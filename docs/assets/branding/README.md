# Aset Penjenamaan UTM

Folder ini menyimpan aset rasmi yang dibekalkan untuk:

- `logo-utm/` — logo Universiti Teknologi Malaysia dalam format web dan sumber reka bentuk.
- `ascend-2030/` — logo UTM ASCEND 2030 dalam variasi warna, hitam, putih, PDF dan AI.

Fail `UMUM ASCEND UTM.pdf` daripada folder asal tidak disalin kerana saiznya 185 MB, melebihi had satu fail GitHub dan bukan aset logo yang diperlukan oleh laman web.

Laman CI menggunakan versi PNG berwarna supaya logo kekal jelas pada latar putih.
