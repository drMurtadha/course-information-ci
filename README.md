# Course Information (CI) — Faculty of Computing

Repository ini menyimpan template, panduan, dan draf Course Information (CI) yang dikemas kini mengikut piawaian **Value Based Education (VBE)** dan **Education for Sustainable Development (ESD)**, hasil daripada Bengkel Pelaksanaan VBE (14 Ogos 2026, Fakulti Komputeran, UTM).

## Struktur Direktori

```
.
├── templates/          # Template CI rasmi (CI_Template, CI_Template_New, CI Checklist, CI_Explanation)
├── guides/              # Panduan langkah demi langkah untuk kemas kini CI
├── references/          # Bahan rujukan (matrix kursus, definisi operasional VBE/ESD)
│   └── matrix-kursus/
│       ├── UG/          # Matrix kursus program Prasiswazah
│       └── PG/          # Matrix kursus program Pascasiswazah
└── courses/              # CI sebenar mengikut kursus
    ├── UG/               # CI kursus Prasiswazah
    └── PG/               # CI kursus Pascasiswazah
```

## Latar Belakang

Template CI baharu memerlukan setiap Course Learning Outcome (CLO) yang dipetakan dengan nilai VBE (Integrity, Synergy, Excellence, Sustainability) atau ESD dinyatakan secara eksplisit dalam wording CLO, berpandukan Operational Definition (OD) masing-masing.

### Proses Kemas Kini CI (7 Langkah)

1. Rujuk matrik kursus rasmi — kenal pasti program, kohort, dan kod kursus yang betul.
2. Sahkan pemetaan PLO ↔ Graduate Attributes selaras antara matrix dan CI.
3. Jika kursus dipetakan dengan nilai VBE/ESD, masukkan nilai tersebut terus ke dalam wording CLO (guna OD sebagai panduan kata kerja/tingkah laku).
4. Pastikan aras Bloom's Taxonomy sesuai program — UG minimum C3/C4, PG minimum C4/C5.
5. Selaraskan kaedah pentaksiran dengan LO baharu — markah sumatif minimum UG ≥30%, PG ≥40%.
6. Kemas kini sinopsis kursus (4 komponen: Course Overview, Main Topics, Learning Approach, Learning Outcomes Summary).
7. Semakan akhir menggunakan tab CI Checklist (15 item).
