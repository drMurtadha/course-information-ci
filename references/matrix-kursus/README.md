## Panduan Pemilihan Nilai

- **VBE:** Setiap program mesti pilih sekurang-kurangnya 2 kursus bagi setiap nilai VBE. Tidak semua kursus perlu menerapkan semua nilai VBE — pilih secara strategik berdasarkan kandungan, aktiviti pembelajaran, dan pentaksiran kursus.
- **ESD:** Setiap program mesti pilih sekurang-kurangnya 2 kursus bagi setiap elemen ESD berkaitan. ESD tidak wajib pada setiap kursus/CLO — hanya petakan jika jelas relevan dan dapat dibuktikan melalui pengajaran, aktiviti pembelajaran, dan pentaksiran.
